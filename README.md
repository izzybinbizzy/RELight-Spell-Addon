# RELight - Spell Addon - SKSE plugin

Copyright (C) 2026 izzydoingit. GPL-3.0-or-later, see `../LICENSE`.

Ships with RELight - Spell Addon and is required by it.

- Adds the mod's settings to SKSE Menu Framework's Mod Control Panel.
- **Lights off while sneaking**, off by default: no spell light turns on while you sneak, and the ones
  already lit go out until you stand up.

Needs SKSE and RE::Light. Without SKSE Menu Framework there is no menu and the settings keep their
defaults.
